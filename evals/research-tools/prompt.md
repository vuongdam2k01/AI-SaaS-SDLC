# Public-web grounding eval

Initial state: EVR-001 contains only an attributable observation that small agencies exchange content drafts with clients. The explicit question is whether public-link review is a currently credible differentiator, and what security/authorization constraints public sources reveal. No feature change is authorized.

Run the plugin’s public-web research method as Evidence Reassessment. Search broadly enough to find primary product/security material, then open and inspect every cited page. Record retrieval dates, source type, the exact supported observation, applicability, limitations, counter-evidence, and freshness risk. Update only evidence and affected discovery synthesis; if the hypothesis weakens, open an issue/question rather than silently changing product truth. Produce EVR-002 while keeping the current product baseline identity.

The captured trace and repository are the evaluated output. A source discovered but not opened cannot support a claim. Snippets, search-result text, model memory, and third-party summaries must not be upgraded into inspected facts.

Prohibited: interviews, outreach, presales, payments, invented researcher agents, fictional user quotes, synthetic URLs presented as public, model self-review, feature/design/test mutation, or “validated demand” language unsupported by inspected evidence.
